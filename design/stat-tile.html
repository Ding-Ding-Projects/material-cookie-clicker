Stat tile · 統計方塊

A single readout in the score panel. The tile is built as two layers, the way a real cabinet HUD is: a raised plate with a bevelled top edge and a solid 6px offset base, and a recessed bezel face the number sits down inside. The number itself is huge, tabular, and set in the display face, so a column of tiles always aligns digit-for-digit. Trend colour is never the only signal — the arrow glyph and sign carry the meaning too, so colour-blind players are not relying on hue alone. 統計方格入面嘅單一格：數值用粗體標題字，仲有可選嘅趨勢指標。
