Material Cookie Clicker design tokens · 設計標記 — Colour

Warm baked-cookie brown/gold as the primary, a golden-cookie tertiary — the exact hex values Material Cookie Clicker already had, kept because they were already appetising, not because the project follows Material Design 3 anymore (it deliberately doesn't; see README.md). Every role pair used for text still has a real, computed WCAG contrast ratio shown on the swatch — not asserted, calculated with the sRGB relative-luminance formula in design/_verify/contrast-check.mjs and re-verified before this file shipped. Arcade spark accent · 火花強調色 — decorative only, never body text

The "saturated accent for golden-cookie moments": --spark/--spark-glow are unverified decorative gradient/glow tones that never carry text of their own, and --spark-ring is a real AA-checked 3:1 non-text tone safe for borders, rings, and "new!" callouts against the surface. Keeping the arcade sparkle separate from the tertiary role means tertiary's own AA-verified text pairs are never put at risk chasing extra saturation.

spark (decorative fill/glow) not a text-bearing role — see decorative note below
spark-ring
--spark and --spark-glow are intentionally not contrast-checked: they are used only as gradient stops inside blurred glow shapes (see cookie-surface.html's golden-cookie overlay) that never have text drawn directly on top of them. If a future surface ever wants to put text on a spark fill, it must use --md-on-surface or --md-tertiary-family text and get its own verified pair added here first.

Computed contrast ratios (live, in-page) · 即時計算對比度

This page recomputes every ratio in your browser, in plain JavaScript, using the same sRGB relative-luminance formula as design/_verify/contrast-check.mjs, so the numbers shown above are not typed constants — open devtools and inspect window.__contrastReport to see the full table for whichever scheme is active.
