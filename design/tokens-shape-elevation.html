Material Cookie Clicker design tokens · 設計標記 — Shape & Depth

Corner radii and a chunky, pressable-depth shadow system, each rendered on a real card so the weight can be judged directly rather than read as a number. This project deliberately does not use Material 3's soft blurred "tonal elevation" — depth here is a solid offset shadow in the surface's own darker shade that visibly compresses flat when you press it, like a real arcade button. Shape scale · 形狀階

Used across the app: full for the cookie surface and pill buttons, xl/lg for dialogs and the prestige gate, md for building rows, upgrade cards and tool cards, sm/xs for chips and badges. Every radius is bigger than this project's original Material 3 scale — timid 4px corners read as productivity software, not a bakery.

Pressable depth · 可撳厚度 — click these

v2 splits the depth system into two paired families so a shadow and the travel that matches it can never drift apart. --drop-1…--drop-4 (4 / 6 / 8 / 10px) are the length a control travels when pressed, which is also the height of the solid base under it; --press-1…--press-4 are the ready-made box-shadows built from those lengths. A control presses by translating exactly --drop-N and dropping its --press-N to none, so it bottoms out flush. v1 topped out at a 4px base; v2 goes to 10px, and the big arcade buttons add a second solid ring in --cabinet-frame-dark so they look seated in the cabinet rather than floating on it. Under prefers-reduced-motion the travel is replaced by an instant inset shade - still a visible state change, just not an animated one.

Depth is a solid offset shadow in a darker shade of the element's own colour (--md-primary-shadow, --md-tertiary-shadow, --md-error-shadow — see tokens-color.html), not a blur. On :active the element translates down by the shadow's own offset and the shadow disappears, so it visibly compresses into the surface. Under prefers-reduced-motion: reduce the translate is removed but the shadow still snaps to flat instantly (an un-animated state change, not motion), so the press is still legible without any movement — try the toggle below.
