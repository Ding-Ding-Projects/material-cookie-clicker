Material Cookie Clicker design tokens · 設計標記 — Type

Two type families doing two different jobs: a bold, blocky display face for headings and big milestone numbers (character, confidence, arcade-poster energy), and a highly legible body face for every reading-heavy surface and every factual figure, always with tabular numerals so digits align in a column. Display face · 標題字型 — character, without a network request

--font-display stacks "Segoe UI Black" (bundled with every supported Windows release, this project's active delivery scope) then "Arial Black" (near-universal cross-platform fallback with the same chunky letterform weight) before dropping to the ordinary body stack. No .woff/.ttf is bundled and no remote font service is used — a bold system face already gives headings the "confident, arcade-poster" character this theme wants, and adding a network dependency for one heading face was judged not worth breaking the fully-self-contained, offline requirement.

Tabular figures · 數字對齊

Every place a number appears repeatedly in a fixed-width context — stat tiles, building costs, CPS deltas, tool-tree progress fractions — sets font-variant-numeric: tabular-nums so digits occupy equal width and align in a column instead of jittering as the value updates. This applies in the body face; no separate monospace font is needed.

Body/CJK-safe fallback stack · 內文／中文字型後備堆疊： "Segoe UI", "Microsoft JhengHei", "PMingLiU", "MingLiU", -apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif

Microsoft JhengHei is the Traditional-Chinese-native face bundled with every supported Windows release, so Cantonese copy renders in a purpose-built CJK face rather than a Latin font's fallback glyphs. Segoe UI leads for Latin text so English stays crisp; JhengHei only engages for CJK code points thanks to normal font-fallback substitution. The display face above is Latin/heading-only — Cantonese headings still render in the bold weight of this body/CJK stack, since "Segoe UI Black" has no CJK glyph coverage to fall back on safely.
