Tool card · 工具卡 — Tools tech tree

Every canonical application feature (command palette, regex builder, authenticator, file converter, local model manager, appearance editor, and so on) doubles as an in-game "tool" the player discovers and unlocks through play, granting a gameplay bonus on unlock. 應用程式自己嘅正式功能（指令面板、正則表達式產生器、驗證器、檔案轉換器等）喺遊戲入面變成玩家可以解鎖嘅「工具」，解鎖之後有遊戲加成。

The unlock gates the game surfacing and the bonus only — never the real feature. · 解鎖淨係影響遊戲內顯示同加成，唔會鎖住真正嘅功能。 Every tool card, in every state, keeps an "Open it now" action in its own clearly bordered callout box — that box is deliberately styled to stand apart from the lock/undiscovered chrome above it, precisely because a chunkier padlock treatment could otherwise make the callout read as part of the lock. It opens the real application feature from settings/the command palette immediately — because that feature has always been available to the player, regardless of tech-tree progress. This is why the action is never greyed out, never hidden behind the silhouette, and appears identically on an undiscovered card and a fully unlocked one. A player must never come away thinking the Regex Builder or the Authenticator itself is "locked" — only its gameplay bonus is.
