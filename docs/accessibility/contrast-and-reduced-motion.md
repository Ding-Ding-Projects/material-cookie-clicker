# Contrast and reduced motion

## Behavior

Text/control contrast remains readable in every theme and state. Reduced motion removes or settles
nonessential animation while preserving exact progress and state through text.

## Configuration

The application follows the operating-system reduced-motion preference. Theme comes from the bought
look tier and application state.

## Failure modes

Historical captures identified unreadable hover and crowded HUD states. Existing contrast scripts
and captures do not prove every new surface or pseudo-state.

## Security and privacy

No status relies on color or motion alone, especially errors, downloads, destructive actions, and
authentication.

## Verification

Use kernel contrast tests, design checks, reduced-motion captures, and targeted built interaction
for each changed state.
