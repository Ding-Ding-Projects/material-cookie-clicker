# Exports and privacy

## Behavior

Every record/view/list/log/setting/artifact is exportable in each faithful applicable format, with
schema, encoding, line endings, active filter range, and loss disclosure.

## Configuration

Structured formats include JSON/JSONL/YAML/TOML/XML/CSV/TSV/Markdown/HTML/SQL and applicable source
forms. Archives use ZIP or fully configurable 7z.

## Failure modes

The baseline has kernel format helpers and limited site exporters, not exhaustive UI, round-trip,
bulk export, or VS Code handoff.

## Security and privacy

Ordinary exports explicitly state omitted secrets and private vocabulary. Paths in archives remain
relative and sensitive export requires consequential confirmation.

## Verification

The kernel CSV test is one formatter check, not surface proof. Require every record type, active
filters, partial failures, round trips, and packaged interaction.
