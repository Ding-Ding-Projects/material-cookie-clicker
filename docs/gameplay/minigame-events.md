# Minigame Events and Lucky Drawer

## Unlocks and schedule

The minigame panel unlocks permanently at 100,000 lifetime baked cookies. Mouse Raids unlock permanently at 1,000,000 lifetime baked cookies. Both thresholds use the preserved baked-cookie history, so prestige does not remove them. The existing prestige tab and prestige action keep their established 1B and 1T thresholds.

After the minigame unlock, a dedicated seeded schedule selects an event every 6–12 minutes. The incoming notice is hidden until the final 30 seconds. A scheduled event never replaces an active event, and the clicker, random events, and production continue while the minigame panel is open. The active board, lifecycle status, and seeded schedule are persisted, including minimized, resumed, restarted, and abandoned states.

## Included minigames

- Klondike Solitaire uses draw-three stock rules, legal tableau/foundation moves, stock recycling, and persisted tableau, waste, foundation, and face-up state.
- Memory Match persists shuffled pairs, safe reveal/match transitions, and attempt count.
- Cookie 2048 persists directional merges, deterministic tile spawning, score, best tile, move count, and win state.
- Minesweeper persists a safe first reveal, mine layout, flood reveal, flags, chord behavior, dimensions, and win/loss state.
- Breakout persists paddle movement, ball stepping, bounce/life loss, bricks, score, pause state, and win state.

Each board is generated from a seeded stream and is updated through validated reducer transitions. A completion grade is recorded as a Golden Token award. Completing three minigames also awards a rare-chain bonus. Daily objectives and achievement milestones use the same duplicate-protected token ledger. These awards are action-based and never generated by offline progress.

## Golden Tokens and Lucky Chance

Golden Tokens can come from Oven Dial completion, minigame grades, daily objectives, achievement milestones, and rare chains. The ledger records each source key once, so a repeated dispatch cannot mint a duplicate award.

The Lucky Chance drawer costs one Golden Token per pull and discloses its five equal reward slots. It can grant cookie bundles, a timed boost, raid supplies, or a rare cosmetic. The draw uses the persisted seeded stream and commits the token deduction, result, injected timestamp, and duplicate-protection state together. When no token is available, no result is written.

## Failure and recovery

The save codec treats the minigame state as a local sidecar to the versioned game save. An absent sidecar is read as an empty suite, preserving older saves without inventing progress. A corrupt or incomplete sidecar falls back to the empty minigame state while the ordinary game save remains available.

This expedited release deliberately has no new test, capture, or UI-run evidence; those remain pending for a later verification pass.
