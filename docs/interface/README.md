## Failure and security boundary

Visual resemblance is not interaction proof. Decorative controls, missing focus, clipped content,
and unconfirmed destructive actions are release defects.

## Verification

The desktop uses the approved hidden-desktop capture route. Site behavior requires built/deployed
interaction rather than source-template inspection.
