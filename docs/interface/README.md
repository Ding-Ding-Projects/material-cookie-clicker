## Design parity and promotion state

- The hand-written parity inventory covers 16/16 checked-in references.
- The negative proof turns 19/19 exact deliberate breaks red and restores green.
- The release check is **red**: all 16 visual-diff reviews remain `defect`, beginning with
  `DIFF_REVIEW_DEFECT` for `achievement-badge--gallery`.
- The 32 current promotion records are being invalidated. They omit 13 generic-contract fields,
  keep capture/build/interaction/privacy records inside the repository rather than one task run
  root, provide no staged transaction or backups, and were generated with hard-coded
  source/process/window identifiers. A fresh clean-source promotion run is required after the
  visual defects are repaired.

Visual parity files and receipts being present therefore does not mean the current interface is
approved, promotion-compliant, or release-ready.
