# Destructive-action confirmation

## Behavior

The gate names the exact action and data, requires two independent keys, then enables a full-range
slider. Emergency exit/Escape cancels and focus returns to the origin.

## Configuration

Motion respects reduced-motion preferences; facts stay exact across languages and funny levels.

## Failure modes

Prestige uses the gate and has built capture evidence, but the baseline does not inventory every
destructive action across app and site.

## Security and privacy

No destructive action runs until both keys and the slider complete. The gate does not replace
authorization or unsaved-work protection.

## Verification

`captures/app/prestige-gate.png` proves the visible prestige state. Keyboard, screen-reader,
reduced-motion, and every-action coverage remain required.
