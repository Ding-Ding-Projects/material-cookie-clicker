# Material Design and product appearance

## Behavior

The universal contract uses Material Design 3 tokens, component anatomy, typography, shape,
elevation, motion, focus, and responsive layout. This game has an explicit owner decision to retain
its bakery-arcade product aesthetic while preserving accessibility requirements.

## Configuration

The game currently sells a progression-based light/dark appearance rung. The complete appearance
editor contract is documented separately and remains incomplete.

## Failure modes

Do not claim universal Material conformance from a token file or a screenshot. Current captures
show the intended game aesthetic, not a complete Material audit.

## Security and privacy

Appearance changes are local presentation only and must not change installed identity or expose
private custom assets.

## Verification

Contrast and theme tests plus light/dark captures cover the present theme. Per-element and design-
reference parity evidence remains outside this baseline.
