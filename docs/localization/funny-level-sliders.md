# Funny-level sliders

## Behavior

English and Cantonese each have an independent persisted slider from 1 (serious) to 5 (maximum
playfulness). Voice may change; action, data, warning, security, and error facts may not.

## Configuration

Both values live in the application settings record and remain independently adjustable.

## Failure modes

The desktop controls persist and render, but current copy has no five-level variants. The site also
lacks complete per-level copy evidence.

## Security and privacy

Humor never softens data loss, money, disability, security facts, or available recovery actions.

## Verification

`settings.test.ts` and `captures/app/settings-sliders.png` prove controls/persistence only, not
variant coverage.
