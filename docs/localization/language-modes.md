# Language modes

## Behavior

English, playful Hong Kong Cantonese, and bilingual modes are selectable. Bilingual keeps a clear
primary/secondary hierarchy rather than duplicating crowded labels blindly.

## Configuration

The selected mode persists outside the game save. English is always available; the current game
also sells Cantonese/bilingual themed controls without tying them to gameplay progress.

## Failure modes

Several accessible names and headings still construct both languages directly and do not obey the
active mode. Site coverage is incomplete.

## Security and privacy

Localization never rewrites commands, paths, identifiers, secrets, or provider-authored facts.

## Verification

Use `settings.test.ts`, the kernel facts-invariant test, and `captures/app/settings-yue.png` plus
`mode-yue.png`.
