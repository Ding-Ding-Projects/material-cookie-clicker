# Appearance editor

## Behavior

The complete editor targets every rendered element, including itself. It includes theme/density,
installed fonts, Word-depth typography, shapes/spacing/elevation, an infinite color picker and
translator, animated rainbow sentinel, presets, import/export, and reset.

## Configuration

Selections persist per element and may participate in schedules. Reduced motion settles animated
rainbow on one hue.

## Failure modes

The desktop baseline provides a bought theme rung and reusable appearance/color logic, not a full
editor. The site has partial theme/color controls without every-element proof.

## Security and privacy

Custom themes are local data. Imports are bounded and validated; they must not execute code or
silently discard unsupported values.

## Verification

Current light/dark captures prove only the theme rung. Every-element interaction, persistence, and
capture evidence remain pending.
