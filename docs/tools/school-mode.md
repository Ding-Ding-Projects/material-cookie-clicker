# School mode

## Behavior

One shared, user-renamable mode forces English and removes Cantonese, bilingual, funny-level,
personal-vocabulary, and dim-sum capabilities from every active surface until locally unlocked.

## Configuration

The shared record, chosen name, and resettable unlock choice propagate live across installed apps.
Deleting the shared application-data record is the documented reset route.

## Failure modes

The baseline contains preference/storage primitives only. There is no cross-application watcher,
credential integration, desktop control, or site equivalent.

## Security and privacy

This is a user-experience lock, not a security boundary. Credentials never enter settings, exports,
logs, captures, or Git history.

## Verification

No built interaction or capture exists; both surfaces remain logic-only/not implemented.
