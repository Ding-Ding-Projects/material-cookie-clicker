# Status Hub

## Behavior

Each project registers real commits, release channel, checks, evidence, and current state with a
shared hub. Every app and page also exposes its own truthful status surface.

## Configuration

Session/project identifiers are stable and access-controlled. A question is delivered only after an
authenticated hub/bridge inbox accepts it.

## Failure modes

Material Cookie Clicker v0.2.55 has no app-owned or site-owned Status Hub implementation. External
agent status cannot substitute for the product surface.

## Security and privacy

Rows contain evidence, never secrets. Hard-coded verdicts and decorative send controls are rejected.

## Verification

Require registration, live update, evidence links, app/site rendering, localized copy, focused
tests, and current captures before changing either matrix row.
