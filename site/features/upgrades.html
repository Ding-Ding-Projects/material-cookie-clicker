Upgrades

Seventy-five upgrades: five global ones plus five stacking tiers for each of the fourteen generators.

Current state

Shipped the upgrade ticket strip is in this release; 79 definitions in src/shared/game/upgrades.ts.

From the running application

See all nine captures in the capture matrix.

What it does

An upgrade is a one-time purchase that permanently multiplies something. There are 79 of them, and that number is not a target — it is what the definition list actually contains:

  • 4 reveal upgrades — Shop Sign (10 cookies), Upgrade Catalogue (50), Steady Hand (100) and Fuel Contract (500). These multiply nothing at all. A fresh save is the cookie and its counter alone, and each of these buys back one piece of the game’s own surface: the shop rail, this very ticket strip, press-and-hold clicking, and the Diesel Depot in the shop rail’s footer. Before the strip exists there is nowhere to buy them from, so the next one appears as a single discovery ticket beside the cookie once its price is within reach.
  • 5 global upgrades, unlocked by lifetime-cookie thresholds. Reinforced Finger doubles click power for 100 cookies; Sturdier Ovens adds 10% to all production; Double Click, Double Trouble doubles click power again; Industrial-Grade Yeast adds 25% to all production; Thousand-Finger Technique triples click power.
  • 70 per-generator upgrades — five tiers for each of the fourteen generators, unlocking at 1, 5, 25, 50 and 100 owned. Each tier doubles that generator's own output, so all five stacked reach a 32× multiplier on that tier at 100 owned.

Four effect kinds exist and no more: a click multiplier, a multiplier on one named generator, a global CPS multiplier, and a reveal — which turns on a piece of the game surface and changes no number anywhere. Unlock conditions are equally small: an owned count of a named generator, a lifetime-cookie threshold, another upgrade already owned, or always available. A reveal gates game panels and one game input behaviour only; it is never allowed to gate a real application feature, which the Tools tech tree’s own contract keeps unconditionally available.

How it is configured

The thresholds and the per-tier multiplier are named constants at the top of the file, and the seventy per-generator upgrades are generated from them rather than typed out, so a change to the ladder cannot leave a stale upgrade behind. Prices for the generated tiers derive from the generator's own base cost.

Presentation is fixed by design/upgrade-card.html: upgrades are ticket-shaped purchases with notches punched out of both edges, a dashed perforation and a price stub, in locked, unlocked-buyable and owned states, with a metallic treatment once owned and a hover tilt that has a still equivalent under reduced motion.

In the shipped build

The upgrade ticket strip sits on the same screen as the cookie and the shop, with its own search field and a live “owned / 79” counter, showing buyable tickets alongside padlocked ones. The strip is not on screen at the start of a run: it arrives with the Upgrade Catalogue, and a save made before progressive disclosure existed is granted the three original reveals on load so it never loses a surface it always had; the Fuel Contract is not granted, because the Diesel Depot is new and no older save can have lost it. The dark-theme capture on the front page shows the same strip rendered from the dark token set.
