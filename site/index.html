Material Cookie Clicker

A cookie clicker for Windows where the application's own features — the command palette, the regex builder, the authenticator, the file converter — are the game's tech tree. Free, unsigned by policy, offline by design, and bilingual in English and Hong Kong Cantonese.

What it is

English

Click a cookie. Buy twenty tiers of increasingly unreasonable machinery, from a Cursor up to a Prism. Spend a hundred and eighty upgrades, chase two hundred and one achievements, catch golden cookies, unlock the application's own twenty features as in-game tools, then ascend and throw it all away for a permanent multiplier. It runs with the network unplugged, it costs nothing, and it never asks you for an account.

Where the project actually is

Where the project actually is

The game is playable, and it now starts plain on purpose. A brand-new save is a white page, the system font and a flat grey disc with the word COOKIE on it: the whole arcade-bakery look is a seven-rung purchase, and so are the window’s own buttons, the Settings panel, the language modes, the search fields and the buy-quantity stepper. Past that, this release ships the game surface — HUD readouts, the raid-supplies shelf, the cookie hero, the docked shop rail with the Diesel Depot status card in its footer, and the upgrade shelf — plus the Diesel Factory, The Home, Achievements, Tools, Statistics, Prestige, Prices and Settings panels, sixteen random events, the Mouse Raid, milk and the Reborn tree, the wandering golden cookie with its Oven Dial minigame, and the automatic-update notice. All 728 tests pass and the application builds. Every panel named here was photographed from the real running build; you can see the photographs in the capture matrix.

What is still honestly unverified, and stays listed here until somebody has actually seen it: the narrow-width shop drawer, which was checked by forcing its breakpoint rather than by really resizing the window, because every capture is one maximised window. Two things that were on this list are now off it: the golden-cookie spawn and its puzzle have both been photographed on the running build, and the Settings panel has now been photographed from a progressed save rather than only a fresh one.

One thing the capture run found by looking rather than by testing, and it is a fault rather than a gap: when all eight console buttons sit on the HUD row, the raid-supplies shelf clips its third plate — Half-HP Whack runs under the shelf’s right-hand edge and loses the end of its own label. It is not a capture artefact and it is not everywhere: the event capture on the random-events page caught the same shelf after an event plate pushed the console buttons onto a second row, and there all three plates read whole. So it is the crowded single-row layout that cuts it, and it is named here rather than framed out of shot.

The installer is unsigned, on purpose and permanently

There is no code-signing certificate and there will not be one. Windows SmartScreen will therefore warn you when you run the installer, and you will have to choose “More info” and then “Run anyway” to continue. That warning is accurate: Windows genuinely cannot verify who published this, and no amount of reassurance on a web page changes that. If you are not comfortable with it, do not install it — the full source is on GitHub and you can build it yourself.

Nobody ever pays anything for this application, and it asks for no account, no key and no network access.

It updates itself, and it tells you what that is worth

An installed copy asks this repository's GitHub releases for a newer version — once, a while after it starts, and then roughly every four hours — using the Squirrel.Windows updater the installer sets up. Nothing about that blocks the game: the check runs outside the window, the download happens in the background, and if there is no network the check simply fails and is logged. When a package has finished downloading, a small card appears in the corner saying Update ready — restart to install, with a Restart button and a Later button. Later hides the card; the update is still there next time you start the game.

What is actually checked: Squirrel downloads the RELEASES index over HTTPS, downloads the package it names, and rejects that package unless its bytes hash to the SHA1 the index recorded. What is not checked, ever: who wrote the index. It is unsigned, like everything else here, so the guarantee is “these bytes match what github.com served for this repository” and never “this update is verified as authentic”. The card in the corner says so in both languages rather than leaving you to assume the stronger version. If you would rather not have this at all, do not install it — run it from source, where there is no updater in the process to begin with.

What you get if you install it today

The game, playable: the single game surface with the cookie, the shop rail and the upgrade strip, plus the Diesel Factory, The Home, Achievements, Tools, Statistics and Prestige panels — all bilingual, all offline. The capture matrix above is what it actually looks like.

Also in this release: a Settings panel, reachable from the first frame of a new save, with a language-mode selector that really does switch the whole application between English, Cantonese and both, and two independent funny-level sliders whose values are stored across restarts.

Not in this release: any per-level difference in the writing — the copy has one voice per language so far, so the funny levels are stored and honoured but change nothing you can read yet. The dark theme is photographed for the game surface only.

How this site is built

This site follows the same design system as the game — the v2 “arcade cabinet” specs in design/: radial oven-glow backgrounds, marquee headings on bevelled plates, solid offset shadows with no blur anywhere, 2–7px borders, and the same colour tokens in light and dark. It is explicitly not Material Design 3; the role names (primary, surface, outline) are kept as vocabulary only.

It is also entirely self-contained. There is no CDN, no remote font, no remote image, no analytics and no network request of any kind: the hero cookie is drawn with CSS gradients, the capture matrix loads PNG files committed alongside these pages, the search index is baked into a local module, and the only external addresses anywhere in this site are the two GitHub links, which you have to click.

Material Cookie Clicker is free, unsigned by permanent policy, and nobody ever pays anything to use it.
